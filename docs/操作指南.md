# 晦明 - 操作指南

## 快速开始

### 1. 安装依赖

```bash
cd D:\03Project\1\huiming
npm install
```

### 2. 启动开发环境

**方式一：浏览器模式（推荐开发）**

```bash
# 同时启动服务器和客户端
npm run dev
```

- 服务器：http://localhost:3000
- 客户端：http://localhost:5173

**方式二：桌面模式（Electron）**

```bash
npm run desktop
```

### 3. 构建生产版本

```bash
# 构建客户端
npm run build

# 构建桌面版
npm run desktop:build
```

## 游戏玩法

### 联机流程

1. **玩家 A** 创建房间
   - 启动游戏 → 输入服务器地址 → 连接
   - 点击「创建房间」
   - 房间自动出现在所有玩家的大厅列表中

2. **玩家 B** 加入房间
   - 启动游戏 → 输入服务器地址 → 连接
   - 在大厅房间列表中看到房间 → 点击「加入」

3. **开始游戏**
   - 双方加入后自动开始

> 也可以复制房间链接直接发送给对方，对方点击链接会自动加入。

## 功能说明

### 连接面板

启动后显示连接面板，可输入：
- 局域网地址：`192.168.1.100:3000`
- 本机地址：`localhost:3000`（开发模式）

历史地址会自动保存。

### 大厅

- 显示所有可用游戏
- 显示当前房间列表
- 可加入等待中的房间

### 断线重连

- 断线后游戏暂停，等待重连
- 45 秒内重连自动恢复
- 超时则对手获胜

### 再来一局

- 游戏结束后双方可选择「再来一局」
- 双方同意后房间重置，重新开始

## 网络配置

### 局域网联机

1. 确保双方在同一局域网
2. 一方创建房间，查看显示的局域网地址
3. 另一方输入该地址连接

### 外网联机（需要穿透）

1. 本地创建房间，记下端口号（默认 3000）
2. 使用穿透软件映射端口：
   - cpolar
   - frp
   - natapp
3. 将穿透后的公网地址填入客户端连接

## 开发指南

### 项目结构

```
huiming/
├── packages/core/      # 平台核心
│   ├── shared/         # 共享类型
│   ├── server/         # 服务端框架
│   └── client/         # 客户端框架
├── games/              # 游戏插件
│   └── huiming/        # 晦明游戏
├── server/             # 服务器入口
├── client/             # 客户端入口
├── desktop/            # Electron 桌面版
└── docs/               # 文档
```

### 添加新游戏

1. 创建 `games/<game-id>/` 目录
2. 实现 `GameServerPlugin` 接口
3. 实现 `GameClientPlugin` 接口
4. 在服务器和客户端注册插件

### Socket 事件

| 方向 | 事件 | 说明 |
|------|------|------|
| C→S | `player:hello` | 握手，发送 playerId 和昵称 |
| S→C | `player:welcome` | 握手确认，返回游戏列表 |
| C→S | `room:create` | 创建房间 |
| C→S | `room:join` | 加入房间 |
| C→S | `room:leave` | 离开房间 |
| C→S | `room:again` | 请求再来一局 |
| C→S | `game:action` | 游戏操作 |
| S→C | `game:stateUpdate` | 状态更新（带版本号） |
| S→C | `game:over` | 游戏结束 |
| S→C | `game:paused` | 对手断线暂停 |
| S→C | `game:resumed` | 对手重连恢复 |
| S→C | `rooms:list` | 房间列表更新 |

## 常见问题

**Q: 无法连接服务器？**
- 检查服务器是否启动
- 检查防火墙设置
- 确认地址格式正确（如 `192.168.1.100:3000`）

**Q: 游戏卡顿？**
- 检查网络延迟
- 刷新页面重试

**Q: 断线后无法重连？**
- 45 秒内重连会自动恢复
- 超时后游戏结束，需重新创建房间
