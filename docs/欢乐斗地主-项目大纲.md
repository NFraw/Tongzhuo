## 1. 游戏概述

### 1.1 游戏简介

斗地主是流行于湖北一带的扑克游戏，玩法简单、娱乐性强。据说源于旧社会时期，人们为了发泄对地主的痛恨，在劳作之后关起门来玩这个游戏。

### 1.2 游戏类型

V1.0 版为单机版，用户与机器人对战。后续计划开发网络版。

## 2. 游戏规则

不同地域规则可能有差异，游戏按如下规则实现。

### 2.1 牌型

| 牌型 | 描述 |
|------|------|
| 王炸 | 大王+小王，最大的牌 |
| 炸弹 | 四张同数值牌（如四个 9） |
| 单牌 | 单张的牌（如红桃 3） |
| 对牌 | 数值相同的两张牌（如梅花 4+ 方块 4） |
| 三张牌 | 数值相同的三张牌（如三个 Q） |
| 三带一 | 数值相同的三张牌 + 1张单牌，例如：333+6 |
| 三带二 | 数值相同的三张牌 + 1对牌，例如：666+33 |
| 顺子 | 五张或更多的连续单牌，不包括 2 和双王 |
| 连对 | 三对或更多的连续对牌，不包括 2 和双王 |
| 飞机 | 二个或更多的连续三张牌，不包括 2 和双王 |
| 飞机带翅膀 | 飞机＋同数量的单牌（或同数量的对牌） |
| 四带二 | 四张点数相同的牌 + 两手牌（两单或两双） |
| 王炸带二 | 王炸 + 两手牌（两单或两双） |

### 2.2 牌型的大小

- 王炸最大，可压任意其他牌型。
- 炸弹比王炸小，比其它牌型大。同为炸弹时按点数比大小。
- 除火箭和炸弹外，其它须牌型相同且总数量相同才能比大小。
- 单牌按点数比大小（不分花色）：`大王 > 小王 > 2 > A > K > Q > J > 10 > 9 > 8 > 7 > 6 > 5 > 4 > 3`
- 对牌、三张同点数牌均按点数比大小。
- 顺子按最大一张牌的点数比大小。
- 飞机带翅膀和四带二按其中的三顺和四张部分比较，副牌不参与大小比较。

### 2.3 游戏角色

参与游戏共三人，两种角色：

- **地主**：1人，分数最高者成为地主，自己一伙。
- **农民**：2人，未抢到地主的玩家，二人一伙。

### 2.4 游戏规则

1. **发牌**：一副牌 54 张，一人 17 张，留 3 张底牌。确定地主前玩家不能看底牌。

2. **叫地主 / 抢地主**：
   - 按出牌顺序轮流进行，每人只能叫一次。
   - 可叫 "1分"、"2分"、"3分" 或 "不叫"。
   - 后抢者只能叫比前人更高的分或不叫。
   - 分值最大者为地主；叫 "3分" 立即结束；都不叫则重新发牌。

3. **第一轮叫地主的玩家**：单机版直接指定用户玩家为第一个叫地主的玩家，也可由系统随机选定。

4. **出牌**：
   - 三张底牌交给地主并亮出。
   - 地主首先出牌，按逆时针顺序依次出牌。
   - 轮到用户跟牌时可选择 "不出" 或出比上家大的牌。
   - 某一玩家出完牌时结束本局。

### 2.5 游戏的胜负

先出完牌的玩家代表的角色获胜：地主先出完则地主胜；任一农民先出完则农民胜。

### 2.6 游戏计分规则

- **底分**：叫地主时的下注分数（1分、2分、3分）。
- **倍数**：初始为 1，每出一个炸弹或王炸翻一倍（留在手上的不算）。

局结束后计算得分：

- **地主胜**：地主 `2 * 底分 * 倍数`，农民 `- 底分 * 倍数`
- **农民胜**：地主 `-2 * 底分 * 倍数`，农民 `底分 * 倍数`

游戏代码中没有处理春天的情况，如有需要可自行添加。

## 3. 游戏相关的类介绍

单机版共需 7 种类型的类：卡牌类、玩家类、窗口类、游戏控制类、线程类、游戏策略类、音频类。

### 3.1 卡牌类

有两个：**单张卡牌类**和**多张卡牌类**。

- **单张卡牌类 Card**：每张扑克牌有花色和点数属性，用于存储和读取卡牌数据。
- **多张卡牌类 Cards**：管理各玩家游戏过程中手中的牌。

### 3.2 玩家类

三个玩家类：玩家类、机器人类、用户玩家类。后两者是玩家类的子类。

- **玩家类 Player**：定义共通属性和方法
  - 属性：角色、类型、性别、头像位置等
  - 方法：设置/获取姓名、性别、得分、角色；玩家切换；抢地主；出牌等
- **机器人玩家类 Robot**：继承父类并重写抢地主和出牌虚函数。
- **用户玩家类 UserPlayer**：继承父类并重写抢地主和出牌虚函数。

### 3.3 窗口类

- **Loading**：游戏开始时加载动画窗口
- **GamePanel**：游戏主窗口类
- **CardPanel**：单张扑克牌窗口，每张牌对应一个窗口对象
- **MyButton**：自定义按钮，美化处理
- **ButtonGroup**：主窗口中的按钮组窗口，供用户抢地主、出牌使用
- **ScorePanel**：游戏分数面板窗口，右上角展示各玩家得分
- **EndingPanel**：游戏结束成绩窗口
- **Countdown**：出牌倒计时窗口，超过20秒未出牌系统默认不出
- **AnimationWindow**：特效动画窗口（王炸、炸弹、飞机、顺子、连对等）

### 3.4 游戏控制类

GameControl 是核心类，管理控制众多核心数据：

- 玩家对象初始化
- 所有扑克牌数据初始化
- 游戏状态：发牌、叫地主、出牌
- 玩家状态：考虑叫地主、考虑出牌、某个玩家获胜
- 游戏数据：玩家卡牌数据、下注和翻倍数据、得分
- 游戏重置和发牌

### 3.5 游戏策略类

两个策略类：出牌类和出牌策略类。

- **出牌类 PlayHand**：对玩家手中的牌进行牌型及点数信息获取，基于规则进行大小比较。
- **出牌策略类 Strategy**：制定出牌策略，是逻辑最复杂、代码量最大的类。实现机器人叫地主/抢地主和出牌功能的算法。也可实现托管功能，但单机版中意义不大。

### 3.6 线程类

两个线程类：

- **RobotGrapLord**：机器人抢地主时创建子线程，结束后销毁。
- **RobotPlayHand**：机器人出牌时创建子线程，结束后销毁。

后续计划修改为线程池实现。

### 3.7 音频类

BGMControl 控制游戏中各种音乐播放：

- 背景音乐
- 抢地主/叫地主提示音乐
- 发牌音乐、选牌音乐
- 牌型、点数提示音乐
- 剩余牌量提示

## 4. 游戏主要组件

开发需完成三大组件：卡牌、玩家、窗口。

### 4.1 卡牌

1. **卡牌窗口**：每张扑克牌是一个窗口对象，实现主窗口中移动及鼠标事件响应，支持点选和框选。每个窗口拥有：承载数据（花色、点数）、展示（正面/背面）、所有者、状态（选中/未选中）。

2. **卡牌数据**：基于面向对象思想，按最小粒度归类。
   - 单张卡牌类：为每个窗口对象存储花色和点数
   - 多张卡牌类：管理各玩家手中的牌，包括发牌、出牌、点数管理、数量管理、排序

### 4.2 玩家

从两个角度分类：

1. **玩家属性**：名字、分数、游戏结果、角色（地主/农民）、性别、头像方位、类型（机器人/非机器人）

2. **游戏控制**：
   - 用户玩家通过主窗口自主操作（叫地主/抢地主、出牌、不出牌）
   - 机器人玩家通过线程按算法完成操作

### 4.3 窗口

除主窗口外还有若干子窗口：

- 按钮组窗口（叫地主和出牌）
- 卡牌窗口（展示扑克牌信息）
- 分数面板窗口（展示当前得分）
- 成绩面板窗口（游戏结束展示成绩）
- 游戏特效窗口（特殊牌型特效动画）

---

## 5. 游戏控制

GameControl 类是程序的神经中枢，统筹协调所有类实现联动。游戏控制主要分为：

- 游戏状态控制
- 玩家状态控制
- 玩家的创建和管理
- 叫地主/抢地主
- 发牌
- 出牌
- 玩家分数管理
- 游戏的重置

以上任何情况都在游戏控制类协调下完成类间的数据传递或事件传递。
